# FarsiFix

FarsiFix یک افزونه مرورگر برای ترجمه سریع متن انتخاب‌شده و تبدیل خودکار متون فارسیِ تایپ‌شده با کیبورد انگلیسی است.

## امکانات
- ترجمه سریع متن انتخاب‌شده
- تشخیص متن‌های فارسیِ اشتباه‌تایپ‌شده
- تبدیل خودکار به فارسی
- پشتیبانی از میانبرهای صفحه‌کلید
- پیکربندی ساده از طریق صفحه تنظیمات افزونه

## نحوه استفاده
1. متن مورد نظر را در صفحه وب انتخاب کنید.
2. از منوی افزونه یا میانبر مربوطه استفاده کنید.
3. اگر متن به‌صورت اشتباه با کیبورد انگلیسی تایپ شده باشد، افزونه پیشنهاد تبدیل می‌دهد.
4. اگر ترجمه لازم باشد، متن به سرویس ترجمه ارسال شده و نتیجه نمایش داده می‌شود.

## نصب
1. این پروژه را در مرورگر کروم/برخوردهای مبتنی بر Chromium بارگذاری کنید.
2. از حالت توسعه‌دهنده استفاده کنید.
3. پوشه پروژه را به عنوان افزونه نصب کنید.

## سیاست حریم خصوصی
برای مشاهده جزئیات کامل درباره داده‌ها، ارسال اطلاعات و نحوه ذخیره‌سازی، به [PRIVACY_POLICY.md](PRIVACY_POLICY.md) مراجعه کنید.

## نکته مهم
- تنظیمات افزونه در حافظه محلی مرورگر ذخیره می‌شوند.
- متن انتخاب‌شده برای ترجمه به سرویس ترجمه ارسال می‌شود.
- اطلاعات فنی ممکن است ثبت شوند.
- متن‌های معمولی تایپ‌شده به‌صورت صریح توسط افزونه ثبت نمی‌شوند.

## توسعه
این افزونه با استفاده از Manifest V3 و JavaScript ساخته شده است و شامل فایل‌های اصلی زیر است:
- `manifest.json`
- `background.js`
- `content.js`
- `lib.js`
- `options.js`

اگر قصد توسعه یا شخصی‌سازی بیشتر را دارید، با بررسی این فایل‌ها می‌توانید منطق افزونه را به‌راحتی تغییر دهید.
